# Herramientas EJCR

Convierte videos y audios en japonés en material de estudio, con Claude Code:

- **Subtítulos** en japonés con traducción al español
- **Tarjetas de Anki** con captura de pantalla y audio
- **Audio condensado** (sin silencios largos)

De la comunidad **En Japonés Con Rafy (EJCR)**.

## Cómo se usa
1. Sigue [`INSTALACION.md`](INSTALACION.md) (una sola vez).
2. Pon tus videos en la carpeta `videos/`.
3. Abre Claude Code en esta carpeta y pídele, por ejemplo:
   - «Descarga este video y hazme subtítulos y mazo de Anki: https://…»
   - «Haz un mazo de Anki para el video "nombre.mp4"»
   - «Hazme subtítulos japonés-español de "nombre.mp4"»
   - «Haz el audio condensado de "nombre.mp4"»

Claude lee las reglas de [`CLAUDE.md`](CLAUDE.md) y las guías de cada tarea, y se encarga de ejecutar todo.

## Importante
- Tú confirmas lo que escuchas: el audio es la fuente, las transcripciones son borradores.
- Las descargas son solo para estudio personal. No compartas los videos descargados.
- Material con derechos de autor: solo para estudio personal. No compartas los mazos ni los audios.
- Para actualizar: descarga de nuevo la carpeta (Code → Download ZIP) o, si usas git, `git pull`.
